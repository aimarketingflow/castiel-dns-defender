🛡️ Safety Layers

1. Auto-failover — DoH errors fall back to plain DNS per-query
2. Auto-disable — 5 consecutive failures → DoH off
3. Signal kill switch — kill -USR1 $(pgrep dad)
4. Shell script — ./doh-killswitch.sh off
5. Config — set use_doh: false in config.yaml and restart
